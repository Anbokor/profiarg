# 🇦🇷 Quatro Clicks — Платформа-каталог и интерактивная карта специалистов в Аргентине

**Quatro Clicks** — двуязычная веб-платформа (**Русский** / **Аргентинский испанский**), объединяющая предпринимателей, мастеров, юристов, переводчиков и экспертов в Буэнос-Айресе и Аргентине с клиентами.

> *Данная платформа предназначена для бесплатного размещения информации о вашей деятельности и направлена на упрощение поиска необходимой услуги в Аргентине как для русскоязычного населения, так и для испаноговорящих.*
> 
> *Esta plataforma está destinada a la publicación gratuita de información sobre tu actividad profesional y orientada a simplificar la búsqueda de servicios en Argentina tanto para la comunidad hispanohablante como rusoparlante.*

---

## 🚀 Основные возможности (Key Features)

1. **3 Режима отображения (Multi-View UI)**:
   - **Сплит-режим (Split View)**: Каталог с карточками слева + интерактивная карта справа с подсветкой пинов при наведении и клике (как на Airbnb / Google Maps).
   - **Каталог (Catalog Grid View)**: Адаптивная сетка карточек специалистов с подробной информацией.
   - **Карта (Full Map View)**: Полноэкранная интерактивная карта с плавающей карточкой активного мастера внизу экрана.

2. **Интерактивная карта (Leaflet + OpenStreetMap)**:
   - Открытые тайлы OpenStreetMap без платных API и без водяных знаков.
   - Кастомные цветные маркеры по категориям с визуальным пингом при выборе.
   - Быстрые кнопки зума к районам: **Palermo, Recoleta, Belgrano, Puerto Madero, Caballito, San Telmo, Vicente López**.
   - Кнопка **«Рядом со мной»** с геолокацией пользователя.
   - Всплывающие превью-карточки мастеров с быстрым переходом в WhatsApp.

3. **Специфика рынка Аргентины (Local Market Nuances)**:
   - **Прямая связь через WhatsApp (`wa.me/+549...`)** с предзаполненным персонализированным сообщением.
   - Поддержка аргентинских телефонных номеров (+54 9 11 ...).
   - Цены в **ARS (песо)**, **USD (доллары)** и статус *«По договорённости»*.
   - Двуязычный интерфейс с учетом аргентинского диалекта (*voseo*, *"Consultá por WhatsApp"*, *"Pedí turno"*, *"Radicación"*).

4. **14 Структурированных категорий услуг**:
   - 🔨 **Ремонт и строительство**: окна ПВХ, электрика, сантехника, отделка под ключ.
   - 💄 **Красота**: маникюр, стрижки, брови, косметология.
   - 🚚 **Перевозки**: грузоперевозки по CABA, переезды, трезвый водитель.
   - 💱 **Обмен валют**: крипта USDT, наличные доллары, песо, рубли P2P.
   - 🌐 **Переводчики**: судебные переводчики CTPCBA, сопровождение, апостили.
   - ⚖️ **Юридические услуги, адвокаты**: DNI, ВНЖ, гражданство через суд, апелляции.
   - 📚 **Обучение**: аргентинский испанский, английский, репетиторы.
   - 🧭 **Туризм**: авторские туры по Буэнос-Айресу, трансферы, Тигре.
   - 🔌 **Ремонт бытовой техники**: кондиционеры, холодильники, термотанки.
   - 🚗 **Авто**: диагностика, подбор авто, проверка по DNRPA и VTV.
   - 🏢 **Недвижимость**: аренда без гарантии, покупка, контракты.
   - 💼 **Работа**: вакансии, подбор персонала.
   - 💻 **IT услуги**: веб-разработка, боты, интеграция с MercadoPago.
   - 🥐 **Продукты питания, магазины**: славянская выпечка, полуфабрикаты, гастрономия.

5. **Интерактивные функции**:
   - **Добавить анкету мастера / бизнеса**: модальное окно с валидацией, верификацией DNI/паспорта, преимуществами и сохранением в `localStorage`.
   - **Биржа заказов**: размещение и отклик на клиентские заявки.
   - **Личный кабинет мастера**: отслеживание заказов и управление профилем.
   - **Избранное**: сохранение понравившихся специалистов в один клик.

## 🛠 Технологический стек (Tech Stack)

| Компонент | Технология | Описание |
| :--- | :--- | :--- |
| **Framework** | **Next.js 15 (React 19, App Router)** | SSR, SEO, быстрая навигация |
| **Язык** | **TypeScript 5** | Строгая типизация моделей данных и интерфейсов |
| **Стилизация** | **Tailwind CSS 3** | Адаптивная мобильная верстка, кастомные анимации |
| **Карта** | **Leaflet + OpenStreetMap** | Быстрый рендеринг, кастомные SVG-маркеры, нулевые затраты на API |
| **Иконки** | **Lucide Icons** | Современный легкий набор векторных иконок |
| **Локализация** | **Bilingual Engine (RU / ES-AR)** | Мгновенный переключатель языка без перезагрузки |
| **Хранилище** | **LocalStorage Engine** | Сохранение пользовательских анкет, отзывов и избранного |

```
│   ├── AddSpecialistModal.tsx    # Форма публикации новой анкеты
│   ├── StatsBanner.tsx           # Баннер со статистикой и доверием
│   └── Footer.tsx                # Подвал сайта со ссылками на районы и рубрики
├── data/
│   ├── seedData.ts               # 16+ детальных реалистичных анкет мастеров
│   ├── categories.ts             # Список категорий с цветами и описанием
│   └── barrios.ts                # Районы CABA и Zona Norte с точными координатами
├── lib/
│   ├── translations.ts           # Словари переводов (Русский / Испанский)
│   ├── storage.ts                # Работа с LocalStorage (анкеты, избранное, отзывы)
│   └── utils.ts                  # Генератор ссылок WhatsApp, форматирование валют
├── types/
│   └── index.ts                  # TypeScript типы (Specialist, Review, Barrio и др.)
├── package.json
└── tsconfig.json
```

## 🚀 Установка и запуск

### 1. Установка зависимостей:
```bash
npm install
```

### 2. Запуск в режиме разработки:
```bash
npm run dev
```
Откройте [http://localhost:3000](http://localhost:3000) в браузере.

### 3. Сборка для продакшна:
```bash
npm run build
npm run start
```
