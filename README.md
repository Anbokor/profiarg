# 🇦🇷 Quatro Clicks — Каталог и интерактивная карта специалистов в Аргентине

**Quatro Clicks** — двуязычная веб-платформа (**Русский** / **Аргентинский испанский**), объединяющая предпринимателей, мастеров, строителей, юристов, переводчиков и экспертов в Буэнос-Айресе и Аргентине с клиентами без посредников.

> *Данная платформа предназначена для бесплатного размещения информации о вашей деятельности и направлена на упрощение поиска необходимой услуги в Аргентине как для русскоязычного населения, так и для испаноговорящих.*
> 
> *Esta plataforma está destinada a la publicación gratuita de información sobre tu actividad profesional y orientada a simplificar la búsqueda de servicios en Argentina tanto para la comunidad hispanohablante como rusoparlante.*

---

## 🧭 Архитектура и принципы платформы (Core Principles)

1. **Максимальная лаконичность и 3-уровневая иерархия**:
   - **Уровень 1 (Главный экран)**: 14 крупных карточек категорий в один широкий столбец без лишнего шума и без тяжелых маркетинговых баннеров.
   - **Уровень 2 (Группы / Подкатегории)**: выбор направления деятельности (например: *Услуги Obras* или *Продажа материалов Materiales*).
   - **Уровень 3 (Специализация)**: выбор конкретной услуги (например: *Окна*, *Электрика*, *Сантехника*).
   - **Уровень 4 (Список мастеров и компактная карта)**: только на конечном уровне открывается список проверенных исполнителей и кнопка развертывания компактной карты.

2. **Карточки исполнителей без цен и хронометража**:
   - В строгом соответствии с концепцией платформы и эскизом заказчика, карточки мастеров **не содержат цен и длительности работ** (услуги индивидуальны и обсуждаются напрямую).
   - Крупный, читаемый заголовок с ID исполнителя (например, `#0001/001`) и названием компании.
   - Четкие бейджи специализации: `[Категория]` `[Группа]` `[Подкатегория]`.
   - Полная портретная фотография мастера (`object-cover object-top`) без обрезания лиц.
   - Правая вертикальная панель быстрых действий: добавление в избранное, телефонный звонок, прямой переход в WhatsApp и подробная анкета.
   - Интерактивная лента фотографий выполненных работ с просмотром в полноразмерном лайтбоксе без сжатия.

3. **Интерактивная карта по требованию (Leaflet + OpenStreetMap)**:
   - Карта вызывается кнопкой на конечном уровне каталога и имеет компактную высоту (250–290px), не перегружая экран.
   - Кастомные цветные пины по категориям с визуальным пингом при выборе.
   - Всплывающие превью-карточки с прямой кнопкой связи через WhatsApp.
   - Полная защита от XSS благодаря экранированию HTML-сущностей (`escapeHtml`) и валидации протоколов (`sanitizeUrl`).

4. **Двусторонняя модерация отзывов и подтверждение сделок**:
   - Клиентские отзывы привязываются к подтвержденным сделкам (Verified Deal).
   - В «Кабинете мастера» реализована вкладка модерации отзывов с возможностью одобрения или отклонения входящих откликов.
   - Генератор персональных ссылок для клиентов после успешного завершения заказа.

5. **Фирменная цветовая палитра и UI-стандарты**:
   - Фоновые подложки в оттенках **RAL 7035** (светло-серый) и **RAL 7004** (сигнальный серый) обеспечивают идеальный контраст для белоснежных карточек-плашек.
   - Красный сигнальный акцент (RAL 3020) вокруг ключевых кнопок меню.
   - Крупный высококонтрастный переключатель языка **RU / ES** с мгновенным переключением без перезагрузки страницы.
   - Полная поддержка навигации кнопкой «Назад» в браузере (синхронизация состояния через Browser History API).

## 🗂 14 Категорий услуг

1. 🔨 **Ремонт, строительство** (*Construcción y reformas*): бетонные работы, кладка, плитка, электрика, сантехника, окна ПВХ, двери, комплексный ремонт.
2. 💄 **Красота** (*Belleza y cuidado*): окрашивание, стрижки, маникюр, педикюр, депиляция, косметология, массаж.
3. 🚚 **Транспортные услуги** (*Transporte y fletes*): легковой трансфер аэропорт EZE/AEP, грузоперевозки по CABA и Аргентине, международная доставка.
4. 💱 **Обмен валюты** (*Cambio de divisas*): наличные USD/ARS, переводы USDT, банковские операции.
5. 🌐 **Услуги переводчика** (*Traductores*): сертифицированный переводчик CTPCBA, устный переводчик, апостили и нотариальное заверение.
6. ⚖️ **Услуги адвокатов и др.** (*Abogados y legales*): ВНЖ, DNI, гражданство через федеральный суд, налоговое консультирование.
7. 📚 **Обучение** (*Educación y cursos*): испанский, английский, математика, ИЗО, русский язык для детей, танго.
8. 🧭 **Туризм** (*Turismo y excursiones*): авторские туры по Буэнос-Айресу, рыбалка, охота, отели, рестораны.
9. 🔌 **Ремонт бытовой техники** (*Reparación de electrodomésticos*): телефоны, стиральные машины, кондиционеры, телевизоры.
10. 🚗 **Авто** (*Autos y mecánica*): прокат авто, ремонт, запчасти, подбор и проверка автомобиля перед покупкой.
11. 🏢 **Недвижимость** (*Inmobiliaria*): аренда и продажа квартир, подбор без гарантийной записи.
12. 💼 **Работа** (*Empleo*): вакансии и резюме в Буэнос-Айресе.
13. 💻 **IT Услуги** (*Servicios informáticos*): изготовление сайтов, системное администрирование, интеграции.
14. 🥐 **Магазины / еда** (*Comercios y alimentos*): продукты питания, кулинария, кондитерские изделия.

## 🛠 Технологический стек (Tech Stack)

| Компонент | Технология | Назначение |
| :--- | :--- | :--- |
| **Фреймворк** | **Next.js 15 (React 19, App Router)** | Высокая производительность, статическая генерация, SSR |
| **Язык** | **TypeScript 5** | Строгая типизация моделей данных, отсутствие незащищенных `any` |
| **Стилизация** | **Tailwind CSS 3** | Адаптивная верстка, переменные RAL 7035 / RAL 7004, Dark Mode |
| **Картография** | **Leaflet 1.9 + OpenStreetMap** | Интерактивные маркеры, отсутствие платных API-ключей |
| **Иконки** | **Lucide React** | Легковесный векторный набор иконок |
| **Локализация** | **Bilingual Engine (RU / ES-AR)** | 100% паритет ключей между словарями русского и аргентинского испанского |
| **Хранилище** | **LocalStorage Engine** | Персистентность анкет, избранного, истории сделок и модерации |

## 🧪 Запуск и тестирование

### Установка зависимостей
```bash
npm install
```

### Запуск в режиме разработки
```bash
npm run dev
```
Сервер будет доступен по адресу `http://localhost:3000`.

### Запуск интеграционных тестов (311 проверок)
```bash
npm test
```
Тестовый набор проверяет:
- Целостность 14 категорий и всех подкатегорий по ТЗ
- Отсутствие цен и продолжительности работ в карточках и анкетах
- Полный двуязычный паритет RU / ES
- Корректность нормализации номеров WhatsApp
- Наличие всех ассетов и фавиконов
- Безопасность и отсутствие XSS

### Статический аудит кода
```bash
node scripts/audit-codebase.mjs
```

### Сборка оптимизированного продакшен-бандла
```bash
npm run build
npm run start
```
